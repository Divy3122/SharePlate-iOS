# Local Food Rescue iOS

An iOS application designed to help small local businesses redirect edible surplus food to nearby community organisations before it becomes waste.

## Project Status

Initial project setup and architecture planning.

## Primary Stakeholder

Owners and managers of small local food businesses managing unsold food near the end of the trading day.

## Planned Architecture

SwiftUI → ViewModels → Use Cases → Repository Protocols → CloudKit

## Planned System Extensions

- WidgetKit Widget Extension
- Notification Content Extension

Further documentation will be added as each feature is implemented.
